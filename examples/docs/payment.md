# 支払い方法

## 利用可能な決済手段

- クレジットカード（VISA / Mastercard / JCB / American Express）
- 代金引換（手数料330円、支払上限は30万円まで）
- コンビニ支払い（前払い、ご注文後発行される番号でお近くのコンビニにてお支払い）
- 銀行振込（前払い、振込手数料はお客様負担）
- キャリア決済（docomo / au / SoftBank）
- 各種QRコード決済（PayPay、楽天ペイ）

## 分割払い

クレジットカード決済に限り、3回・6回・12回の分割払いをお選びいただけます。
分割手数料はカード会社の規定によります。分割払いをご希望の場合は
決済画面の「支払い回数」でお選びください。

## 領収書の発行

マイページの「注文履歴」から、注文ごとに領収書（PDF）をダウンロードできます。
宛名の指定が必要な場合は、注文時の備考欄にご記入ください。

## 支払いに関するトラブル

決済エラーが発生した場合は、カード情報の入力ミスや利用限度額超過が
主な原因です。解消しない場合はカード会社に直接お問い合わせいただくか、
別の決済方法をお試しください。二重決済が発生した場合は
サポート窓口までご連絡いただければ確認のうえ返金いたします。
