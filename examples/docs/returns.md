# 返品・返金ポリシー

## 返品の条件

商品到着後 **30日以内** であれば、未使用・未開封の商品に限り返品を受け付けます。
食品、化粧品、下着など衛生上の理由で開封後の返品ができない商品は対象外です。
セール品・アウトレット品は返品不可としていますので、購入前にご確認ください。

## 返品の手順

1. マイページの「注文履歴」から対象の注文を選び、「返品を申請する」ボタンを押してください。
2. 返品理由を選択すると、返送用の伝票番号が発行されます。
3. 商品を元の梱包材で梱包し、発行された伝票を貼付して発送してください。
4. 弊社倉庫で商品の状態を確認後、3営業日以内に返金処理を行います。

## 返金方法

返金は購入時にご利用の決済方法に準じます。クレジットカード決済の場合は
カード会社の締め日により、返金の反映まで1〜2ヶ月かかることがあります。
代金引換でご購入いただいた場合は、お客様の銀行口座へお振込みいたします。
返品送料はお客様都合の場合はお客様負担、商品の不良・誤配送の場合は
弊社負担となります。

## 交換について

サイズ違い・カラー違いによる交換をご希望の場合は、返品ではなく
「交換」としてマイページからお申し込みください。在庫がある場合のみ
交換対応が可能です。在庫がない場合は返金でのご案内となります。
